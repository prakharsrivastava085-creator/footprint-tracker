# 🔒 Digital Footprint Tracker

A local-first privacy tracker that helps you:
- Track all your online accounts in one place
- Score your privacy risk across services
- Check if your email appeared in data breaches (HIBP)
- Generate GDPR / CCPA deletion request emails

## 🚀 Live Demo
👉 **[Open the app](https://prakharsrivastava085-creator.github.io/footprint-tracker/)**

## Features
- **Dashboard** – Privacy score, category charts, risk distribution
- **My Accounts** – Add, edit, delete, import via CSV, export
- **Scan / Import** – CSV import + Have I Been Pwned breach check
- **Deletion Requests** – GDPR Article 17 / CCPA / General email templates
- **100% local** – All data stored in your browser, nothing sent to any server

## Tech Stack
- Pure HTML + CSS + JavaScript (zero dependencies to install)
- Chart.js for visualisations
- localStorage for data persistence
